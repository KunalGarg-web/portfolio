# Kunal Garg Portfolio

- index.html
- about.html
- services.html
- projects.html
- assets/
  - css/style.css
  - js/main.js

Replace the sample image/video URLs in `projects.html` and `index.html` with files from `assets/images/` and `assets/videos/` when your real work is ready.
